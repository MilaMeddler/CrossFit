# Система подсчета результатов CrossFit Tournament

Этот документ описывает унифицированный алгоритм подсчета результатов с настраиваемыми дивизионами и тайбрейками.

## Обновление от 2026-03-18

Логика подсчета была унифицирована для всех турниров:
- Применяется единая логика с приоритетом дивизионов и тайбрейками
- Добавлена поддержка 5 дивизионов: Elite, RX, Intermédiaire, Scaled, Foundations
- Для каждого турнира можно настроить активные дивизионы
- Разница между Open и обычными турнирами только в способе хранения дивизиона

## Дивизионы

### Фиксированный порядок приоритета

Все турниры используют единую систему приоритетов дивизионов (меньше = лучше):

```
Elite (1) > RX (2) > Intermédiaire (3) > Scaled (4) > Foundations (5)
```

**При сравнении результатов сначала сравнивается дивизион, потом результат!**

Это значит:
- Elite с результатом 10:00 ВСЕГДА выше RX с результатом 5:00
- RX с результатом 100 reps ВСЕГДА выше Scaled с результатом 200 reps
- Дивизион имеет абсолютный приоритет над результатом

### Настройка активных дивизионов

- Каждый турнир имеет настраиваемый список активных дивизионов
- Хранится в `tournaments.active_divisions` (массив TEXT[])
- По умолчанию: `['rx', 'scaled', 'foundations']`
- Организатор выбирает нужные дивизионы при создании турнира
- Порядок приоритета остаётся фиксированным

### Хранение дивизионов

- **Обычные турниры (is_open = false)**: дивизион фиксируется при регистрации в `tournament_participants.division`
- **Open турниры (is_open = true)**: дивизион указывается для каждого результата в `scores.division`

## Типы WOD

### 1️⃣ For Time (На время)

**Цель:** Выполнить задание как можно быстрее

**Поля в базе данных:**
- `wod_type = 'time'`
- `value_time` - время выполнения в секундах
- `is_completed` - завершён ли WOD (true/false)
- `value_int` - количество повторений (если не завершён, time cap)
- `tiebreak_time` - время тайбрейка (если не завершён)

**Правила сравнения:**

1. ✅ Завершившие (is_completed = true) ВСЕГДА лучше не завершивших
2. ⏱️ Оба завершили → меньше времени = лучше
3. 🔢 Оба НЕ завершили → больше повторений = лучше
4. ⏲️ При равенстве повторений → меньше tiebreak_time = лучше

**Примеры:**

| Спортсмен | Результат | is_completed | Ранг | Почему |
|-----------|-----------|--------------|------|---------|
| Анна      | 4:30      | true         | **1** | Завершила, лучшее время |
| Мария     | 5:00      | true         | **2** | Завершила, время хуже |
| Ольга     | 95 reps   | false        | **3** | Не завершила, но больше повторений |
| Елена     | 90 reps (4:50) | false   | **4** | Не завершила, меньше повторений |

---

### 2️⃣ AMRAP / Reps (Максимум повторений)

**Цель:** Сделать как можно больше повторений/раундов

**Поля в базе данных:**
- `wod_type = 'reps'`
- `value_int` - целое количество повторений
- `value_decimal` - дробное количество (например, 5.5 раундов)

**Правила сравнения:**

⬆️ **Больше повторений = лучше**

**Примеры:**

| Спортсмен | Результат | Ранг |
|-----------|-----------|------|
| Иван      | 250 reps  | **1** |
| Петр      | 230 reps  | **2** |
| Сергей    | 210 reps  | **3** |

---

### 3️⃣ Weight (Вес / 1RM)

**Цель:** Поднять максимальный вес

**Поля в базе данных:**
- `wod_type = 'weight'`
- `value_int` - вес в килограммах (целое)
- `value_decimal` - вес в килограммах (дробное)

**Правила сравнения:**

⬆️ **Больший вес = лучше**

**Примеры:**

| Спортсмен | Результат | Ранг |
|-----------|-----------|------|
| Андрей    | 150 kg    | **1** |
| Михаил    | 140 kg    | **2** |
| Дмитрий   | 135 kg    | **3** |

## 1. Обычный формат турнира (is_open = false)

### Описание
Турниры, где участники регистрируются с фиксированным дивизионом на всё соревнование.

### Основные характеристики

Дивизион определяется при регистрации участника на турнир и сохраняется в `tournament_participants.division`.

### Алгоритм подсчета

#### Шаг 1: Определение ранга для каждого WOD

Используется единая логика с приоритетом дивизионов:

**Сортировка:**
1. Приоритет дивизиона: Elite (1) > RX (2) > Intermédiaire (3) > Scaled (4) > Foundations (5)
2. Внутри дивизиона - сравнение результатов по типу WOD

#### Шаг 2: Подсчет общего балла (Overall)

1. **Фильтрация участников:**
   - По полу (M/F/all)
   - По дивизиону (из списка активных дивизионов турнира)
   - Дивизион берётся из `tournament_participants.division`

2. **Начисление очков за WOD:**
   - Если есть результат: очки = ранг в WOD с учётом приоритета дивизионов
   - Если нет результата: очки = последнее место в категории

3. **Итоговый рейтинг с тайбрейками:**

   **Тайбрейк 1:** Сумма очков (меньше = лучше)

   **Тайбрейк 2:** Приоритет дивизиона
   ```
   Elite (1) > RX (3) > Intermédiaire (5) > Scaled (7) > Foundations (9)
   ```

   **Тайбрейк 3:** Сравнение отсортированных рангов
   - Ранги сортируются: [1, 2, 5] vs [1, 3, 4]
   - Сравниваются поэлементно
   - Меньший ранг = лучше

#### Пример расчета

Турнир с 3 WOD, категория RX Мужчины (5 участников):

| Участник | WOD 1 | WOD 2 | WOD 3 | Сумма | Место |
|----------|-------|-------|-------|-------|-------|
| Иван     | 1     | 2     | 1     | 4     | 1     |
| Петр     | 2     | 1     | 3     | 6     | 2     |
| Сергей   | 3     | 3     | 2     | 8     | 3     |
| Андрей   | 4     | 5     | 4     | 13    | 4     |
| Михаил   | 5     | 4     | 5     | 14    | 5     |

## 2. Формат CrossFit Open (is_open = true)

### Основная концепция

В формате **Open** спортсмен может **выполнять каждый WOD в разных дивизионах**. Дивизион указывается для каждого результата отдельно.

**Главное отличие:**
- Обычный турнир: дивизион выбирается 1 раз при регистрации
- Open турнир: дивизион выбирается для каждого WOD отдельно

### Алгоритм подсчета - Пошагово

#### ШАГ 1: Определение ранга для каждого WOD

1. **Собираются все результаты** участников (с учётом фильтра по полу)

2. **Результаты сортируются** по функции `compareOpenScores()`:
   - **Приоритет 1:** Дивизион (Elite > RX > Scaled > Foundations)
   - **Приоритет 2:** Результат внутри дивизиона (по типу WOD)

3. **Присваивается ранг** - позиция в отсортированном списке

**Пример WOD 1 (For Time):**

```
Результаты (сырые):
- Мария:  4:00 (RX)
- Анна:   5:30 (Elite)
- Ольга:  6:00 (RX)  
- Елена:  5:00 (Scaled)

Сортировка (сначала дивизион, потом результат):
1. Анна    - 5:30 (Elite)   → Ранг 1 ✅ (Elite приоритет 1)
2. Мария   - 4:00 (RX)      → Ранг 2 (RX приоритет 2)
3. Ольга   - 6:00 (RX)      → Ранг 3 (RX приоритет 2)
4. Елена   - 5:00 (Scaled)  → Ранг 4 (Scaled приоритет 4)
```

**Важно:** Анна получила ранг 1, хотя её время хуже, потому что Elite имеет высший приоритет!

---

#### ШАГ 2: Определение профиля участника

Профиль определяется по **всем результатам** участника:

**Примеры профилей:**

| WOD 1 | WOD 2 | WOD 3 | Профиль | Пояснение |
|-------|-------|-------|---------|-----------|
| RX | RX | RX | **rx** | Все WOD в RX = чистый профиль |
| RX | Scaled | RX | **mixed_rx** | Есть RX + другие = смешанный RX |
| Scaled | Scaled | Scaled | **scaled** | Все WOD в Scaled = чистый профиль |
| Elite | RX | Scaled | **mixed_elite** | Есть Elite = смешанный Elite |
| Scaled | Foundations | Scaled | **mixed_scaled** | Scaled + Foundations = смешанный Scaled |

**Визуальные бейджи:**
- `elite` → 🔴 **EL** (красный)
- `mixed_elite` → 🔴 **MX** (светло-красный)
- `rx` → 🟠 **RX** (оранжевый)
- `mixed_rx` → 🟠 **MX** (светло-оранжевый)
- `intermediaire` → 🟣 **IN** (фиолетовый)
- `scaled` → 🔵 **SC** (синий)
- `mixed_scaled` → 🔵 **MX** (светло-синий)
- `foundations` → 🟢 **F** (зелёный)

---

#### ШАГ 3: Подсчет общего балла

1. **Суммируются ранги** всех WOD:
   ```
   Total Points = WOD1_rank + WOD2_rank + WOD3_rank + ...
   ```

2. **Если нет результата** для WOD:
   ```
   Ранг = последнее место в категории
   ```

**Правило:** Меньше очков = лучше место!

---

#### ШАГ 4: Итоговая сортировка (3 тайбрейка)

##### **Тайбрейк 1: Сумма очков** (меньше = лучше)

Если сумма одинаковая → переходим к тайбрейку 2.

##### **Тайбрейк 2: Приоритет профиля** (меньше = лучше)

**Порядок приоритетов:**

```
Elite (1) > Mixed Elite (2) > RX (3) > Mixed RX (4) >
Intermédiaire (5) > Mixed Inter (6) > Scaled (7) > 
Mixed Scaled (8) > Foundations (9) > Mixed (10)
```

**Пример:**
```
Мария:  профиль 'rx' (3)
Ольга:  профиль 'mixed_rx' (4)
→ Мария выше (чистый rx лучше смешанного)
```

Если профили одинаковые → переходим к тайбрейку 3.

##### **Тайбрейк 3: Сравнение отсортированных рангов**

Ранги всех WOD сортируются по возрастанию и сравниваются поэлементно:

**Пример:**
```
Ольга: [3, 1, 1] → sorted [1, 1, 3]
Елена: [1, 2, 2] → sorted [1, 2, 2]

Сравнение:
- Позиция 0: 1 === 1 → равны
- Позиция 1: 1 < 2 → Ольга лучше! ✅
```

### Фильтрация по дивизионам

#### При фильтре "Все" (all):

- ✅ Показываются **все** участники
- ✅ Ранжирование с приоритетом дивизионов
- ✅ Elite выше RX, RX выше Scaled

#### При фильтре конкретного дивизиона (например, "RX"):

- ✅ Показываются **только** участники с чистым профилем `rx`
- ❌ Участники с `mixed_rx` **НЕ показываются**
- ✅ Ранжирование только между RX участниками

**Важно:** Учитываются только те, у кого **ВСЕ** результаты в RX!

## Визуальные различия в интерфейсе

### Обычный формат
- Фильтр категорий: RX, Scaled, Foundations
- Категория участника фиксирована при регистрации
- Нет значка "CrossFit Open"

### Open формат
- Фильтр дивизионов: rx, scaled, foundations, all
- Дивизион указывается для каждого результата
- Отображается оранжевый значок "[OPEN]"
- Цветные бейджи профиля участника (RX, MX, SC, F)
- Под результатом каждого WOD показывается дивизион

## Таблицы базы данных

### tournaments
- `is_open` (BOOLEAN) - флаг формата Open
- `active_divisions` (TEXT[]) - активные дивизионы турнира
  - Возможные значения: `elite`, `rx`, `intermediaire`, `scaled`, `foundations`
  - По умолчанию: `['rx', 'scaled', 'foundations']`

### scores
- `division` (VARCHAR) - дивизион для Open (только для is_open = true)
- `tiebreak_time` (INTEGER) - время тайбрейка в секундах
- `is_completed` (BOOLEAN) - завершен ли WOD
- `value_time` (INTEGER) - время в секундах (For Time)
- `value_int` (INTEGER) - повторения или вес
- `value_decimal` (DECIMAL) - дробные значения

### tournament_participants
- `division` (VARCHAR) - дивизион участника (для is_open = false)
  - Возможные значения: `elite`, `rx`, `intermediaire`, `scaled`, `foundations`
