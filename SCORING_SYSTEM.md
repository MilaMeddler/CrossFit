# Система подсчета результатов CrossFit Tournament

Этот документ описывает унифицированный алгоритм подсчета результатов с настраиваемыми дивизионами и тайбрейками.

## Обновление от 2026-03-18

Логика подсчета была унифицирована для всех турниров:
- Применяется единая логика с приоритетом дивизионов и тайбрейками
- Добавлена поддержка 5 дивизионов: Elite, RX, Intermédiaire, Scaled, Foundations
- Для каждого турнира можно настроить активные дивизионы
- Разница между Open и обычными турнирами только в способе хранения дивизиона

---

## Дивизионы

### Фиксированный порядок приоритета

Все турниры используют единую систему приоритетов дивизионов (меньше = лучше):

```
Elite (1) > RX (2) > Intermédiaire (3) > Scaled (4) > Foundations (5)
```

### Настройка активных дивизионов

- Каждый турнир имеет настраиваемый список активных дивизионов
- Хранится в `tournaments.active_divisions` (массив TEXT[])
- По умолчанию: `['rx', 'scaled', 'foundations']`
- Организатор выбирает нужные дивизионы при создании турнира
- Порядок приоритета остаётся фиксированным

### Хранение дивизионов

- **Обычные турниры (is_open = false)**: дивизион фиксируется при регистрации в `tournament_participants.division`
- **Open турниры (is_open = true)**: дивизион указывается для каждого результата в `scores.division`

---

## 1. Обычный формат турнира (is_open = false)

### Описание
Турниры, где участники регистрируются с фиксированным дивизионом на всё соревнование.

### Основные характеристики

Дивизион определяется при регистрации участника на турнир и сохраняется в `tournament_participants.division`.

### Алгоритм подсчета (унифицированный)

#### 1. Определение ранга для каждого WOD

Используется единая логика с приоритетом дивизионов:

**Сортировка с учётом дивизиона:**
```
1. Приоритет дивизиона: Elite (1) > RX (2) > Intermédiaire (3) > Scaled (4) > Foundations (5)
2. Внутри дивизиона - сравнение результатов
```

**For Time (на время):**
```
1. is_completed = true: меньше времени = лучше
2. is_completed = false: больше повторений = лучше
3. При равенстве повторений: меньше tiebreak_time = лучше
4. Завершившие ВСЕГДА выше не завершивших
```

**AMRAP/Reps:**
```
Больше повторений = выше ранг
```

**Weight:**
```
Больший вес = выше ранг
```

#### 2. Подсчет общего балла (Overall)

1. **Фильтрация участников:**
   - По полу (M/F/all)
   - По дивизиону (из списка активных дивизионов турнира)
   - Дивизион берётся из `tournament_participants.division`

2. **Начисление очков за WOD:**
   - Если есть результат: очки = ранг в WOD с учётом приоритета дивизионов
   - Если нет результата: очки = последнее место в категории

3. **Итоговый рейтинг с тайбрейками:**

   **Тайбрейк 1:** Сумма очков (меньше = лучше)

   **Тайбрейк 2:** Приоритет дивизиона
   ```
   Elite (1) > RX (3) > Intermédiaire (5) > Scaled (7) > Foundations (9)
   ```

   **Тайбрейк 3:** Сравнение отсортированных рангов
   - Ранги сортируются: [1, 2, 5] vs [1, 3, 4]
   - Сравниваются поэлементно
   - Меньший ранг = лучше

#### 3. Пример расчета

Турнир с 3 WOD, категория RX Мужчины (5 участников):

| Участник | WOD 1 | WOD 2 | WOD 3 | Сумма | Место |
|----------|-------|-------|-------|-------|-------|
| Иван     | 1     | 2     | 1     | 4     | 1     |
| Петр     | 2     | 1     | 3     | 6     | 2     |
| Сергей   | 3     | 3     | 2     | 8     | 3     |
| Андрей   | 4     | 5     | 4     | 13    | 4     |
| Михаил   | 5     | 4     | 5     | 14    | 5     |

### Функции кода
- `calculateRankings()` - основная функция подсчета (строка 570)
- `compareRegularScores(a, b, wod)` - сравнение результатов (строка 376)

## 2. Формат CrossFit Open (is_open = true)

### Описание
Турниры формата Open, где участник может выполнять каждый WOD в любом дивизионе.

### Основные характеристики

#### Дивизионы
Дивизион указывается **для каждого результата** в `scores.division`.
Участник может менять дивизион между WOD.

Активные дивизионы настраиваются в `tournaments.active_divisions`.

#### Дополнительные поля в scores
- `division` (VARCHAR) - дивизион для конкретного результата
- `tiebreak_time` (INTEGER) - время тайбрейка в секундах
- `is_completed` (BOOLEAN) - завершен ли WOD или достигнут time cap

### Алгоритм подсчета

Используется та же унифицированная логика, что и для обычных турниров.

#### 1. Определение ранга для каждого WOD

**Приоритет дивизиона:**
```
Elite (1) > RX (2) > Intermédiaire (3) > Scaled (4) > Foundations (5)
```

**Сравнение результатов** - аналогично обычным турнирам.

#### 2. Подсчет общего балла (Overall)

1. **Фильтрация участников:**
   - По полу (M/F/all)
   - По дивизиону (rx/scaled/foundations/all)
   - ВАЖНО: участник включается в дивизион только если ВСЕ его результаты в этом дивизионе

2. **Начисление очков за WOD:**
   - Если есть результат в выбранном дивизионе: очки = ранг среди участников этого дивизиона
   - Если нет результата или другой дивизион: очки = последнее место в категории

3. **Профиль участника (Division Profile):**
   Определяется по всем результатам участника:
   - **elite** - все результаты в elite
   - **mixed_elite** - есть elite + другие
   - **rx** - все результаты в rx
   - **mixed_rx** - есть rx + другие (кроме elite)
   - **intermediaire** - все результаты в intermediaire
   - **mixed_intermediaire** - есть intermediaire + scaled/foundations
   - **scaled** - все результаты в scaled
   - **mixed_scaled** - есть scaled + foundations
   - **foundations** - все результаты в foundations

4. **Итоговый рейтинг с тайбрейками:**

   **Тайбрейк 1:** Сумма очков (меньше = лучше)

   **Тайбрейк 2:** Приоритет профиля дивизиона
   ```
   Elite (1) > Mixed Elite (2) > RX (3) > Mixed RX (4) >
   Inter (5) > Mixed Inter (6) > Scaled (7) > Mixed Scaled (8) > Foundations (9)
   ```

   **Тайбрейк 3:** Сравнение отсортированных рангов
   - Ранги сортируются: [1, 2, 5] vs [1, 3, 4]
   - Сравниваются поэлементно
   - Меньший ранг = лучше

#### 3. Пример расчета

Турнир Open с 3 WOD, все дивизионы:

| Участник | WOD 1       | WOD 2       | WOD 3       | Профиль  | Ранги       | Сумма | Место |
|----------|-------------|-------------|-------------|----------|-------------|-------|-------|
| Анна     | 1 (rx)      | 1 (rx)      | 2 (rx)      | rx       | [1, 1, 2]   | 4     | 1     |
| Мария    | 2 (rx)      | 2 (rx)      | 1 (rx)      | rx       | [1, 2, 2]   | 5     | 2     |
| Ольга    | 3 (rx)      | 1 (scaled)  | 1 (scaled)  | mixed_rx | [1, 1, 3]   | 5     | 3*    |
| Елена    | 1 (scaled)  | 2 (scaled)  | 2 (scaled)  | scaled   | [1, 2, 2]   | 5     | 4**   |

*Мария и Ольга имеют сумму 5, но:
- Тайбрейк 2: rx (приоритет 1) > mixed_rx (приоритет 2) → Мария выше

**Ольга и Елена:
- Тайбрейк 2: mixed_rx (приоритет 2) > scaled (приоритет 3) → Ольга выше

#### 4. Особенности фильтрации

**При фильтре "all":**
- Показываются все участники
- Ранжирование учитывает приоритет дивизиона
- rx участники всегда выше scaled/foundations

**При фильтре конкретного дивизиона (например, "scaled"):**
- Показываются только участники, у которых ВСЕ результаты в scaled
- Ранжирование только внутри этого дивизиона
- Участники с mixed профилем не отображаются

#### 5. Отображение результатов

**Для отдельного WOD:**
- Рядом с результатом показывается дивизион
- Цветные бейджи: RX (оранжевый), Scaled (синий), Foundations (зеленый)

**Для общего рейтинга:**
- Возле имени показывается профиль дивизиона (цветной бейдж)
- Под каждым WOD результатом указывается дивизион
- Отображается значок "CrossFit Open" в заголовке

### Функции кода
- `calculateOpenRankings()` - основная функция подсчета Open (строка 457)
- `compareOpenScores(a, b, wod)` - сравнение результатов Open (строка 334)
- `divisionPriority(division)` - приоритет дивизиона (строка 327)
- `athleteDivisionProfile(wodScoresData)` - определение профиля участника (строка 432)

## Визуальные различия в интерфейсе

### Обычный формат
- Фильтр категорий: RX, Scaled, Foundations
- Категория участника фиксирована при регистрации
- Нет значка "CrossFit Open"

### Open формат
- Фильтр дивизионов: rx, scaled, foundations
- Дивизион указывается для каждого результата
- Отображается оранжевый значок "CROSSFIT OPEN"
- Цветные бейджи профиля участника (RX, MX, SC, F)
- Под результатом каждого WOD показывается дивизион

## Таблицы базы данных

### tournaments
- `is_open` (BOOLEAN) - флаг формата Open
- `active_divisions` (TEXT[]) - активные дивизионы турнира
  - Возможные значения: `elite`, `rx`, `intermediaire`, `scaled`, `foundations`
  - По умолчанию: `['rx', 'scaled', 'foundations']`

### scores
- `division` (VARCHAR) - дивизион для Open (только для is_open = true)
- `tiebreak_time` (INTEGER) - время тайбрейка в секундах
- `is_completed` (BOOLEAN) - завершен ли WOD
- `value_time` (INTEGER) - время в секундах (For Time)
- `value_int` (INTEGER) - повторения или вес
- `value_decimal` (DECIMAL) - дробные значения

### tournament_participants
- `division` (VARCHAR) - дивизион участника (для is_open = false)
  - Возможные значения: `elite`, `rx`, `intermediaire`, `scaled`, `foundations`
