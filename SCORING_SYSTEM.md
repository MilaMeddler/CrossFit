# Система подсчета результатов CrossFit Tournament

Этот документ описывает алгоритмы подсчета результатов для двух типов турниров: обычные турниры и турниры формата CrossFit Open.

---

## 1. Обычный формат турнира (is_open = false)

### Описание
Стандартная система подсчета для местных турниров, где участники регистрируются на определенный уровень сложности.

### Основные характеристики

#### Категории участников
- **RX** (Elite) - элитный уровень
- **INTER/Scaled** - средний уровень
- **SCALE/Foundations** - начальный уровень

Уровень определяется при регистрации участника на турнир и сохраняется в таблице `tournament_participants.level`.

### Алгоритм подсчета

#### 1. Определение ранга для каждого WOD

Для каждого WOD результаты сортируются по правилу:

**For Time (на время):**
```
1. Завершившие WOD ранжируются по времени (меньше = лучше)
2. Не завершившие (time cap) ранжируются по количеству повторений (больше = лучше)
3. При равенстве повторений учитывается tiebreak_time (меньше = лучше)
4. Завершившие ВСЕГДА выше не завершивших
```

**AMRAP/Reps (на повторения):**
```
1. Больше повторений = выше ранг
2. Учитываются value_int или value_decimal
```

**Weight (на вес):**
```
1. Больший вес = выше ранг
```

#### 2. Подсчет общего балла (Overall)

1. **Фильтрация участников:**
   - По выбранному полу (M/F/all)
   - По выбранной категории (RX/INTER/SCALE/all)
   - Используется уровень из регистрации участника

2. **Начисление очков за WOD:**
   - Если есть результат: очки = ранг в WOD (1 место = 1 очко, 2 место = 2 очка и т.д.)
   - Если нет результата: очки = последнее место в категории

3. **Итоговый рейтинг:**
   - Суммируются очки со всех WOD
   - Меньше очков = лучше рейтинг
   - При равенстве очков участники делят место

#### 3. Пример расчета

Турнир с 3 WOD, категория RX Мужчины (5 участников):

| Участник | WOD 1 | WOD 2 | WOD 3 | Сумма | Место |
|----------|-------|-------|-------|-------|-------|
| Иван     | 1     | 2     | 1     | 4     | 1     |
| Петр     | 2     | 1     | 3     | 6     | 2     |
| Сергей   | 3     | 3     | 2     | 8     | 3     |
| Андрей   | 4     | 5     | 4     | 13    | 4     |
| Михаил   | 5     | 4     | 5     | 14    | 5     |

### Функции кода
- `calculateRankings()` - основная функция подсчета (строка 570)
- `compareRegularScores(a, b, wod)` - сравнение результатов (строка 376)

## 2. Формат CrossFit Open (is_open = true)

### Описание
Специальная система подсчета, имитирующая официальный CrossFit Open. Главное отличие - участник может выполнять разные WOD в разных дивизионах.

### Основные характеристики

#### Дивизионы
Дивизион указывается **для каждого результата** (не при регистрации):
- **rx** - элитный дивизион
- **scaled** - масштабированный дивизион
- **foundations** - базовый дивизион

Хранится в `scores.division`.

#### Дополнительные поля в scores
- `division` (VARCHAR) - дивизион для конкретного результата
- `tiebreak_time` (INTEGER) - время тайбрейка в секундах
- `is_completed` (BOOLEAN) - завершен ли WOD или достигнут time cap

### Алгоритм подсчета

#### 1. Определение ранга для каждого WOD

**Приоритет дивизиона:**
```
rx (1) > scaled (2) > foundations (3)
```

Участник в rx ВСЕГДА будет выше участника в scaled/foundations, даже если результат хуже.

**Сравнение внутри одного дивизиона:**

**For Time:**
```
1. is_completed = true И is_completed = true:
   - Меньше времени = лучше (value_time)

2. is_completed = true И is_completed = false:
   - Завершивший ВСЕГДА выше

3. is_completed = false И is_completed = false:
   - Больше повторений = лучше (value_int)
   - При равенстве: меньше tiebreak_time = лучше
```

**AMRAP/Reps:**
```
1. Больше повторений = лучше
```

#### 2. Подсчет общего балла (Overall)

1. **Фильтрация участников:**
   - По полу (M/F/all)
   - По дивизиону (rx/scaled/foundations/all)
   - ВАЖНО: участник включается в дивизион только если ВСЕ его результаты в этом дивизионе

2. **Начисление очков за WOD:**
   - Если есть результат в выбранном дивизионе: очки = ранг среди участников этого дивизиона
   - Если нет результата или другой дивизион: очки = последнее место в категории

3. **Профиль участника (Division Profile):**
   Определяется по всем результатам участника:
   - **rx** - все результаты в rx
   - **mixed_rx** - есть rx + другие дивизионы
   - **scaled** - все результаты в scaled
   - **mixed_scaled** - есть scaled + foundations
   - **foundations** - все результаты в foundations

4. **Итоговый рейтинг с тайбрейками:**

   **Тайбрейк 1:** Сумма очков (меньше = лучше)

   **Тайбрейк 2:** Приоритет профиля дивизиона
   ```
   rx (1) > mixed_rx (2) > scaled (3) > mixed_scaled (4) > foundations (5)
   ```

   **Тайбрейк 3:** Сравнение отсортированных рангов
   - Ранги сортируются по возрастанию: [1, 2, 5] vs [1, 3, 4]
   - Сравниваются поэлементно: первый с первым, второй со вторым и т.д.
   - Меньший ранг = лучше

#### 3. Пример расчета

Турнир Open с 3 WOD, все дивизионы:

| Участник | WOD 1       | WOD 2       | WOD 3       | Профиль  | Ранги       | Сумма | Место |
|----------|-------------|-------------|-------------|----------|-------------|-------|-------|
| Анна     | 1 (rx)      | 1 (rx)      | 2 (rx)      | rx       | [1, 1, 2]   | 4     | 1     |
| Мария    | 2 (rx)      | 2 (rx)      | 1 (rx)      | rx       | [1, 2, 2]   | 5     | 2     |
| Ольга    | 3 (rx)      | 1 (scaled)  | 1 (scaled)  | mixed_rx | [1, 1, 3]   | 5     | 3*    |
| Елена    | 1 (scaled)  | 2 (scaled)  | 2 (scaled)  | scaled   | [1, 2, 2]   | 5     | 4**   |

*Мария и Ольга имеют сумму 5, но:
- Тайбрейк 2: rx (приоритет 1) > mixed_rx (приоритет 2) → Мария выше

**Ольга и Елена:
- Тайбрейк 2: mixed_rx (приоритет 2) > scaled (приоритет 3) → Ольга выше

#### 4. Особенности фильтрации

**При фильтре "all":**
- Показываются все участники
- Ранжирование учитывает приоритет дивизиона
- rx участники всегда выше scaled/foundations

**При фильтре конкретного дивизиона (например, "scaled"):**
- Показываются только участники, у которых ВСЕ результаты в scaled
- Ранжирование только внутри этого дивизиона
- Участники с mixed профилем не отображаются

#### 5. Отображение результатов

**Для отдельного WOD:**
- Рядом с результатом показывается дивизион
- Цветные бейджи: RX (оранжевый), Scaled (синий), Foundations (зеленый)

**Для общего рейтинга:**
- Возле имени показывается профиль дивизиона (цветной бейдж)
- Под каждым WOD результатом указывается дивизион
- Отображается значок "CrossFit Open" в заголовке

## Визуальные различия в интерфейсе

### Обычный формат
- Фильтр категорий: RX, Scaled, Foundations
- Категория участника фиксирована при регистрации
- Нет значка "CrossFit Open"

### Open формат
- Фильтр дивизионов: rx, scaled, foundations
- Дивизион указывается для каждого результата
- Отображается оранжевый значок "CROSSFIT OPEN"
- Цветные бейджи профиля участника (RX, MX, SC, F)
- Под результатом каждого WOD показывается дивизион

## Таблицы базы данных

### tournaments
- `is_open` (BOOLEAN) - флаг формата Open

### scores
- `division` (VARCHAR) - дивизион для Open (rx/scaled/foundations)
- `tiebreak_time` (INTEGER) - время тайбрейка в секундах
- `is_completed` (BOOLEAN) - завершен ли WOD
- `value_time` (INTEGER) - время в секундах (For Time)
- `value_int` (INTEGER) - повторения или вес
- `value_decimal` (DECIMAL) - дробные значения

### tournament_participants
- `level` (VARCHAR) - уровень для обычных турниров (RX/INTER/SCALE)
