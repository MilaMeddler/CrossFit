## 🔍 Диагностика проблем

### Проблема: Не загружается сайт
```bash
1. Проверить GitHub Pages:
   - Settings → Pages → "Your site is live at..."

2. Проверить Supabase:
   - Dashboard → Project не должен быть Paused

3. Проверить Console (F12):
   - Смотреть на ошибки в красном
```

### Проблема: Не работает вход в admin.html
```bash
1. Проверить что пользователь создан:
   - Supabase → Authentication → Users

2. Проверить email подтвержден:
   - Если не подтвержден: Users → ... → Confirm email

3. Проверить в Console:
   - Должно быть "✅ Login successful"
   - Если есть ошибки - скопировать текст ошибки
```

### Проблема: Атлет не может ввести результат
```bash
1. Проверить что RLS политики применены:
   - Supabase → SQL Editor
   - Запустить: SELECT * FROM pg_policies WHERE tablename = 'scores';
   - Должно быть 4 политики: select_public, insert_public, update_admin, delete_admin

2. Если политик нет:
   - Применить supabase-security-policies.sql заново
```

### Проблема: Спортсмены без результата не показываются
```bash
1. Проверить версию leaderboard.html:
   - Должна быть строка: "const lastPlace = filtered.length;"

2. Обновить страницу с очисткой кэша:
   - Ctrl+Shift+R (или Cmd+Shift+R)
```
