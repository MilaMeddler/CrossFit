# 🏋️ CrossFit Competition System

Система управления турнирами CrossFit с поддержкой обычного формата и формата Open.

## 🎯 Основные возможности

- ✅ **Управление турнирами** - создание индивидуальных и командных соревнований
- ✅ **Формат Open** - спортсмены выбирают дивизион для каждого WOD
- ✅ **5 дивизионов** - Elite, RX, Intermédiaire, Scaled, Foundations
- ✅ **Настраиваемые дивизионы** - выбор активных дивизионов для турнира
- ✅ **Режим обслуживания** - включение/выключение доступа к сайту
- ✅ **Аутентификация** - вход через Supabase Auth
- ✅ **RLS политики** - безопасность на уровне базы данных
- ✅ **Leaderboard** - таблица лидеров с фильтрами и тайбрейками
- ✅ **Интерфейс судьи** - быстрый ввод результатов
- ✅ **Личный кабинет** - спортсмены видят свои результаты

## 🚀 Быстрый старт

### 1. Supabase проект

1. Проверьте статус проекта на https://supabase.com
2. Если проект "Paused" → нажмите "Restore project"
3. Примените RLS политики из `supabase-security-policies.sql`

### 2. Создайте админ-пользователя

```sql
-- В Supabase Dashboard → Authentication → Users
-- Add user с email и паролем
```

### 3. Настройте конфигурацию

Обновите `config.js` с вашими данными Supabase:

```javascript
const SUPABASE_URL = 'https://ваш-проект.supabase.co';
const SUPABASE_ANON_KEY = 'ваш-ключ';
```

### 4. Откройте сайт

- **Главная:** `index.html`
- **Админ:** `admin.html` (требуется вход)
- **Судья:** `judge.html`
- **Таблица лидеров:** `leaderboard.html`

## 📊 Дивизионы

Система поддерживает 5 дивизионов с фиксированным порядком приоритета:

1. **Elite** (1) - элитный уровень
2. **RX** (2) - стандартный уровень
3. **Intermédiaire** (3) - средний уровень
4. **Scaled** (4) - облегченный уровень
5. **Foundations** (5) - начальный уровень

Приоритет дивизиона важнее результата!

## 🏆 Форматы турниров

### Обычный формат (is_open = false)

- Дивизион выбирается при регистрации
- Фиксирован на весь турнир
- Хранится в `tournament_participants.division`

### Формат Open (is_open = true)

- Дивизион выбирается для каждого WOD
- Участник может менять дивизион
- Хранится в `scores.division`
- Профили: чистые (rx) и смешанные (mixed_rx)

## 📝 Типы WOD

### For Time (на время)
- Меньше времени = лучше
- Завершившие > не завершивших
- Tiebreak по повторениям

### AMRAP (максимум повторений)
- Больше повторений = лучше
- Считаются целые раунды + повторения

### Weight (вес)
- Больший вес = лучше
- Используется для 1RM

## 🎯 Режим обслуживания

Админы могут включить режим обслуживания:

- Блокирует доступ для всех пользователей
- Показывает сообщение о техническом обслуживании
- Настраивается в `admin.html`
- Хранится в таблице `app_settings`
